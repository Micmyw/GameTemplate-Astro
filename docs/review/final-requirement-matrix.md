# Final design requirement matrix

This matrix maps every section of
`docs/superpowers/specs/2026-08-19-seo-game-site-design.md` to concrete
implementation, automated checks, CI/gates, evidence, and current status.
Statuses mean:

- `PASS`: repository behavior has fresh automated or source-output evidence;
- `MANUAL`: the implementation exists but the named external/manual observation
  must be recorded at release time;
- `NOT APPLICABLE`: a later approved requirement explicitly removed the item;
- `BLOCKED`: real infrastructure, account, domain, OAuth, or game-package input
  is unavailable and no completion claim is permitted.
